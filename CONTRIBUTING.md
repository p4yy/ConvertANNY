# Contributing

Bug reports, corrections and code contributions are welcome.

## Before opening an issue

- Check existing issues for the same problem.
- For a bug, include the ConvertANNY version, Windows version, steps to reproduce and the result you expected. Remove personal data from logs and screenshots.
- For a feature request, describe the task you want to complete and the behavior that would help.
- Report security vulnerabilities privately; see [SECURITY.md](SECURITY.md).

## Changes

1. Open an issue first for a large change so its scope can be discussed.
2. Keep pull requests focused and describe the behavior they change.
3. Follow the surrounding code style and preserve third-party notices and licenses.
4. Run the checks relevant to your change. The release workflow verifies updater behavior, builds the Windows application and installer, and checks bundled conversions.
