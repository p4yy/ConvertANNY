# Security

Please do not post details of an unpatched security vulnerability in a public issue.

Use GitHub's **Report a vulnerability** option on the repository's **Security** page to send a private report. Include the affected version, steps to reproduce, and any relevant impact. If private vulnerability reporting is unavailable, open an issue asking how to contact the maintainer; do not include exploit details there.

For ordinary bugs or feature requests, use the public issue templates.
