# Privacy

ConvertANNY runs file conversions on your PC. Your files are not uploaded for ordinary local conversions. Results are saved locally, beside the original by default.

Some optional features use the internet. They contact the provider needed for that feature:

- Phone sharing can create a link on your local network, a temporary internet link through Cloudflare, or a temporary upload through the service you select.
- Cloud-folder sharing uses the cloud service and folder you configure.
- Link playback and optional helpers or models can download software or model files from their providers. Models used for background removal and speech transcription run locally once downloaded.
- Update checks contact the release repository only when you configure one in the app.
- Crash reports are offered with a prompt. A report is sent only if you choose to send it.

Online features may send the selected files, links, or requests to the provider that delivers that feature. Review the selected destination before sharing. You can use local conversion features without enabling online sharing.

For feature requirements and behavior, see the [feature guide](FEATURES.md). To report a suspected privacy or security issue, follow [Security](../SECURITY.md).
