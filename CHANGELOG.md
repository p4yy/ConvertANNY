# Release notes

Notable changes for each release are listed here.

## 0.1.1 — 2026-11-07

- Keep the app, installer, update checks and release asset names on one version source.
- Publish Windows releases from matching version tags, with conversion verification, source and checksums.
- Add setup, release, privacy, security and contribution guides and issue templates.
- Refresh the repository README with app screenshots and direct support links.

## 0.1.0 — 2026-11-06

First public release.

- Convert and work with images, documents, PDFs, audio, video, archives and other supported files.
- Use the desktop workspace, keyboard and mouse gestures, and optional File Explorer integration.
- Includes batch jobs, Activity history, output controls, preferences and command-line operations.
- Optional sharing, helper downloads and speech or image models are available when needed.
- Windows installer, matching source archive and SHA-256 checksums are available on the [release page](https://github.com/p4yy/ConvertANNY/releases/tag/v0.1.0).
