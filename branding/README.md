# ConvertANNY branding

Brand assets for ConvertANNY by Ace App Co.

| Folder | Contents |
| --- | --- |
| `source/` | Logo reference artwork |
| `icons/png/` | App icon exports |
| `icons/windows/` | Windows ICO |
| `wordmark/` | Wordmarks and README footer |
| `animation/` | Animated logos |

The application uses the icon resources in `src/assets/`. Windows package artwork is in `packaging/StoreAssets/`.
